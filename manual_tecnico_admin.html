⚙️ Manual Técnico de Administración

Este documento es tu guía técnica para operar la plataforma TeInvitoApp. Contiene los enlaces de acceso directo, explicaciones de la base de datos y cómo gestionar los eventos de tus clientes.

1. Arquitectura y Servidores

  • Código Fuente: Alojado en tu cuenta de GitHub (gerzavala40-bit/invitaciones-digitales).
  • Hosting: Vercel (Se actualiza automáticamente cada vez que se suben cambios a GitHub).
  • Base de Datos: PostgreSQL (conectada mediante Prisma ORM). Vercel gestiona las actualizaciones de las tablas automáticamente.

2. Enlaces del Panel de Control

Dashboard Principal: Ver todos los eventos y estadísticas /admin
Crear Nuevo Evento: Formulario para dar de alta a un cliente /admin/events/new
Control de Puerta (Scanner): App para la recepción /scanner

3. Cómo crear y gestionar un Evento

Paso 1: Alta del Evento

Ingresa a /admin/events/new. Completa el formulario con los datos de los novios, fecha, dirección del salón y plantilla elegida. Al hacer clic en "Crear", el sistema generará automáticamente la URL única (el "slug").

Paso 2: Gestionar Confirmados (RSVP)

Desde el Panel Principal (/admin), haz clic en un evento para entrar a su panel específico. Allí verás la lista en vivo de todos los invitados que han confirmado.

Paso 3: Asignar Mesas (Importar/Exportar)

En el panel del evento específico:

  1. Haz clic en "Exportar Excel". Esto te bajará la lista de invitados.
  2. Envíale el Excel al cliente para que rellene la columna "Mesa".
  3. MUY IMPORTANTE: Indícale al cliente que NO borre ni modifique la primera columna (ID_SISTEMA).
  4. Una vez que te devuelvan el Excel, entra al panel y haz clic en "Importar Excel". Sube el archivo y las mesas se actualizarán automáticamente en la base de datos.

4. Seguridad y Scanner QR

Para usar el escáner de la puerta (/scanner), el personal de recepción necesita dos datos:

  • El Código del Evento (slug): Es la parte final de la URL del cliente (Ej: si la web es teinvitoapp.com.ar/boda-ana-y-juan, el código es boda-ana-y-juan).
  • El PIN de acceso: Por defecto, el sistema asigna el PIN 1234 a todos los eventos nuevos creados desde el formulario. (En el futuro, podemos agregar un campo en el formulario de creación para que elijas el PIN manualmente).
¿Cómo funciona el escáner a nivel técnico?
El QR contiene el ID único del invitado en la base de datos. La API /api/scan recibe el QR, valida que pertenezca al evento correcto mediante el PIN, comprueba si el campo attended es falso, lo cambia a verdadero, y devuelve el número de mesa.

5. Modificaciones de Diseño Avanzadas (Demos)

Si deseas cambiar la música, los íconos o crear un nuevo diseño (Demo) usando plantillas de Canva:

  1. Exporta el HTML desde Canva.
  2. Colócalo en la carpeta public/ con el nombre demo-[nombre].html.
  3. Puedes ejecutar los scripts de limpieza (Node.js) que creamos en el proyecto (ej: node fix-music-script.js) para estandarizar los botones y el reproductor de música.
  4. Sube los cambios a GitHub mediante los comandos:
    git add .
    git commit -m "Nuevo diseño"
    git push
  5. Vercel detectará el cambio y lo publicará en vivo en menos de 1 minuto.
