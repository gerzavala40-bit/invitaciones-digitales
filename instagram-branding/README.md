## Cómo usar los SVG

Los archivos SVG se pueden:
1. **Abrir en el navegador** para ver el preview
2. **Importar en Canva** (arrastrar el archivo)
3. **Convertir a PNG** con herramientas online (svgtopng.com)
4. **Editar** en Figma, Illustrator o Inkscape

Para convertir a 1080x1080 PNG (listo para Instagram):
- Usá https://svgtopng.com o
- En Chrome: abrí el SVG → click derecho → "Guardar imagen como" PNG
